## 1. Overview

MPGuino is an open-source, Arduino-based fuel consumption display that connects inline with your vehicle's fuel injector signal wire and vehicle speed sensor (VSS). It computes and displays:

- Instantaneous, current-trip, and tank-level fuel economy
- Speed, fuel rate, fuel used, distance, engine RPM
- Time to empty, distance to empty, remaining fuel
- Engine run time, motion time
- Alternator voltage (optional)
- Idle / engine-off coasting (EOC) sub-totals (optional)

Data is updated twice per second. All settings are stored in EEPROM and survive power cycles.

## 2. Supported Hardware

MPGuino can be compiled for several specified hardware targets selected in `configs.h`:

| Board | Processor | Notes |
|---|---|---|
| Legacy MPGuino | ATmega328P | Original ecomodder.com circuit. 3 buttons, 16x2 LCD display |
| JellyBeanDriver (JBD) | ATmega328P | Runs at 20 MHz. 3 buttons, 16x2 LCD display |
| Arduino Mega2560 | ATmega2560 | Most features available. Button and display options must be specified separately |
| TinkerKit! LCD module | ATmega32U4 | 5-button analog mux, 16x2 LCD display |
| MPGuino Colour Touch (abbalooga) | ATmega2560 | ILI9341 TFT + touchscreen + Bluetooth |

> For fuse settings when using avr-gcc directly: `lfuse:0xf7 hfuse:0xd9 efuse:0x07`

MPGuino can also be configured for use with 16x2, 20x2, or 20x4 LCD screens.

## 3. Electrical Connections

### Fuel Injector

MPGuino senses two edges of the injector pulse:

| Hardware | Injector Open | Injector Close |
|---|---|---|
| Legacy / JBD | PD2 (INT0), Digital 0 | PD3 (INT1), Digital 1 |
| TinkerKit! LCD | PD2 (INT2), Digital 0 | PD3 (INT3), Digital 1 |
| Mega2560 | PE4 (INT4), Digital 2 | PE5 (INT5), Digital 3 |

### Vehicle Speed Sensor (VSS)

MPGuino senses pulse transitions of the VSS pulse train, and supports either mechanical VSS which requires switch debouncing, or clean digital pulse trains generated by the vehicle's electronics.

| Hardware | VSS Pin |
|---|---|
| Legacy / JBD | PC0 (PCINT8), A0 |
| TinkerKit! LCD | PB7 (PCINT7), Digital 11 |
| Mega2560 | PK0 (PCINT16), A8 |

### Optional Sensors

**Alternator voltage** — uses a resistor-divider and 1N4004 diode (see header of `mpguino_tav.ino` for schematic). Connects to A2 (legacy), A2 (Mega2560), or A2 (TinkerKit!).

**Chrysler MAP / Baro sensor** — uses a Chrysler MAP sensor with 2.2 kΩ series resistor to A1 (legacy/Mega) or A2 (TinkerKit!). An optional baro sensor connects to A2 / A3. See section 9.5, Chrysler MAP Correction for details

### Buttons (Legacy / Mega2560)

Three physical buttons: **Left**, **Middle**, **Right**

Buttons can be pressed separately or in combination. Pressing the button for approximately 1/2 second is interpreted as a "long-press" button press, and is handled differently from a normal duration "short-press" button press.

| Hardware | Left | Middle | Right |
|---|---|---|---|
| Legacy | PC3, A3 | PC4, A4 | PC5, A5 |
| Mega2560 | PK3, A11 | PK4, A12 | PK5, A13 |

### Buttons (Analog multiplexed or TWI 5-button)

**Multiplexed analog buttons** (josemapiro wiring or 5-position switch) are also supported via a single ADC pin with resistor ladder.

**Adafruit RGB LCD shield** buttons are accessed over TWI.

Five physical buttons: **Left**, **Center**, **Right**, **Up**, **Down**

Buttons can be pressed separately or in combination, depending on what hardware is used for the switches for the analog multiplexed option. For instance, normal microbuttons could all be pressed at once, but switch-based joysticks would likely not allow a combination of down and up to be pressed simultaneously. Pressing the button for approximately 1/2 second is interpreted as a "long-press" button press, and is handled differently from a normal duration "short-press" button press.

## 4. Startup

On power-up, MPGuino:

1. Displays the version banner and build date briefly on the LCD.
2. Checks EEPROM integrity; re-initialises defaults if the signature does not match.
3. Restores the last-used display screen and cursor positions from EEPROM.
4. Restores saved trips from EEPROM (if Auto-Save is enabled).
5. Enters the main display loop.

Firmware builds that change the EEPROM storage layout intentionally use a different hidden layout version/signature. After flashing one of those builds, MPGuino will reset stored settings to defaults on first boot; review calibration and display settings afterward.

## 5. Button Navigation

MPGuino uses **short press** and **long press** on each button. Typical behaviour:

| Action | Effect |
|---|---|
| **Short Left** | Move to previous screen / scroll up in a menu |
| **Short Right** | Move to next screen / scroll down in a menu |
| **Long Left** | Enter menu / confirm left action (context-dependent) |
| **Long Right** | Enter menu / confirm right action (context-dependent) |
| **Short Middle** | Context action (e.g. reset trip, arm drag test) |
| **Long Middle** | Go to top menu |

> Exact button mappings depend on the hardware button option compiled in (`useLegacyButtons`, `useAnalogButtons`, `useAdafruitRGBLCDbuttons`, etc.) and on which display screen is currently active.

**Adafruit RGB LCD shield cross-config:** The shield's 5 directional buttons (Select, Up, Down, Left, Right) map to the same logical short/long actions.

After the **Button Timeout** (configurable, in seconds), button input is considered idle, and will contribute toward MPGuino going to sleep.

## 6. Main Display Screens

From the main display, short Left/Right cycles through pages. Each page shows four values in a 2×2 grid.

| Page | Top-Left | Top-Right | Bottom-Left | Bottom-Right |
|---|---|---|---|---|
| **Instrument** | Instant Speed | Alternator V (or Eng RPM) | Instant Fuel Rate | Instant Fuel Economy |
| **Custom** | Instant FE | Instant Speed | Instant Fuel Rate | Current FE |
| **Instant / Current** | Instant FE | Instant Speed | Current FE | Current Distance |
| **Instant / Tank** | Instant FE | Instant Speed | Tank FE | Tank Distance |
| **Current** | Current Speed | Current FE | Current Distance | Current Fuel Used |
| **Tank** | Tank Speed | Tank FE | Tank Distance | Tank Fuel Used |
| **EOC / Idle** *(optional)* | Current EOC dist | Current Idle fuel | Tank EOC dist | Tank Idle fuel |
| **Current Data** | Current Eng Run Time | Current Fuel Used | Current Motion Time | Current Distance |
| **Tank Data** | Tank Eng Run Time | Tank Fuel Used | Tank Motion Time | Tank Distance |
| **Current EOC/Idle** *(optional)* | Cur EOC Eng Time | Cur EOC Fuel | Cur EOC Motion | Cur EOC Distance |
| **Tank EOC/Idle** *(optional)* | Tank EOC Eng Time | Tank EOC Fuel | Tank EOC Motion | Tank EOC Distance |
| **Remaining** | Tank Fuel Used | Remaining Fuel | Time to Empty | Distance to Empty |

> EOC/Idle pages appear only when `trackIdleEOCdata` is enabled at compile time.

When the engine is idling or coasting (EOC), the display automatically switches to a condensed idle/EOC overlay showing relevant sub-totals, then reverts when driving resumes.

When Instant Fuel Economy is displayed, and the vehicle is stopped, that function automatically switches to Instant Fuel Rate, and will continue showing Instant Fuel Rate until the vehicle resumes motion.

### Metric vs Imperial

Toggled via Settings → Display & Format → **Metric (1=Yes)**:
- **Imperial (default):** MPG (US), miles, mph, lbs, psi
- **Metric:** L/100km (or km/L), km, km/h, kg, Pa

### Alternate FE Format

Settings → Display & Format → **AltFEformat (1=Yes)** switches between MPG and L/100km (or km/L) regardless of the metric flag.

## 9. Settings Menu

Navigate to **Settings** from the top menu. Use short Left/Right to scroll through categories, short Middle to select. Inside each category, use short Left/Right to move between parameters and the number-editor to change values.

### Number Editor

When editing a parameter with the 3-button button configuration:
- Short Left / Short Right move the cursor left/right to either a digit or to OK or XX (cancel)
- Long Left decrements the selected digit
- Long Right increments the selected digit
- Short Middle saves and exits
- Long Middle cancels (reverts to previous value)

When editing a parameter with the 5-button button configuration:
- Short Left / Short Right move the cursor left/right to either a digit or to OK or XX (cancel)
- Short Up / Short Down increments/decrements the selected digit
- Long Left decrements the selected digit
- Long Right increments the selected digit
- Short Middle saves and exits
- Long Middle cancels (reverts to previous value)

Status line shows **Param Changed**, **Param Unchanged**, or **Param Reverted**.

### 9.2 Fuel Injector

| Parameter | Description |

### 9.5 Chrysler MAP Correction *(optional)*

For late-model Chrysler vehicles with MAP-sensor-based injector correction (requires `useChryslerMAPCorrection`). Late model Chrysler vehicles use a single returnless fuel line from the fuel tank to the engine, which is not modulated to intake manifold pressure, but is instead held constant. Thus, there is a variable pressure differential between the constant fuel pressure and the variable intake manifold vacuum. This has to be adjusted in real time, which this version of MPGuino is well capable of. Barometric pressure is also required in order to calculate absolute fuel pressure, and is normally held to be static. However, for traveling through mountainous terrain or other varying elevations, this is not necessarily a valid assumption, so this version of MPGuino can also support an optional barometric sensor which is another Chrysler MAP sensor exposed to ambient air, and wired to feed into MPGuino directly.

| Parameter | Description |
|---|---|
| MAPfloor (mV) | MAP sensor output at vacuum (0 pressure) in millivolts |
| MAPceiling (mV) | MAP sensor output at maximum pressure in millivolts |
| MAPrng psi*1000 | MAP sensor pressure range × 1000 |
| MAPofst psi*1000 | MAP sensor pressure offset × 1000 |
| BaroPrs psi*1000 | Fixed barometric pressure × 1000 (if no baro sensor is selected) |
| BaroFloor (mV) | Barometric sensor output at vacuum (0 pressure) in millivolts (if baro sensor is selected via `useChryslerBaroSensor`) |
| BaroCeiling (mV) | Barometric sensor output at maximum pressure in millivolts (if baro sensor is selected via `useChryslerBaroSensor`) |
| BaroRng psi*1000 | Barometric sensor pressure range × 1000 (if baro sensor is selected via `useChryslerBaroSensor`) |
| BaroOfst psi*1000 | Barometric sensor pressure offset × 1000 (if baro sensor is selected via `useChryslerBaroSensor`) |

## 10. Trip Management

MPGuino maintains three rolling trip accumulators:

| Trip | Description |
|---|---|
| **Instant** | Rolling average over the last half-second sample window |
| **Current** | Since last manual or auto reset (e.g. start of a journey segment) |
| **Tank** | Since last tank fill-up |

### Resetting Trips

From a main display screen, a **long-left** or **long-right** press (depending on configuration) enters the trip reset / save menu:

| Action | Description |
|---|---|
| Reset Current | Clears the Current trip accumulator |
| Reset Tank | Clears the Tank trip accumulator |

### Saved Trips (EEPROM)

When `useSavedTrips` is enabled:
- **Auto-Save:** Current and Tank trips are written to EEPROM on Park. They are reloaded on next power-on.
- **Manual Save/Restore:** Via the trip save menu under the base menu.
- On successful auto-restore, the LCD briefly shows **"AutoRestore Done"**.
- On successful auto-save, the LCD briefly shows **"AutoSave Done"**.

### Partial Refuel *(optional)*

When `usePartialRefuel` is enabled, a partial refuel amount can be entered to adjust the Tank accumulator without a full reset.

### Window Trip Filter

When `useWindowTripFilter` is enabled, MPGuino smooths instant fuel economy readings using a 4-sample rolling window to reduce jitter from modern OBDII-era engine computers.

## 11. Drag Race / Acceleration Test

Accessed via **Top Menu → Accel Test** (requires `useDragRaceFunction`).

### Sub-menu Options

| Item | Description |
|---|---|
| Stats | View last completed run results |
| Arm Accel Test | Manually arm the test (waits for vehicle to stop, then go) |
| Test AutoArm (1=Y) | Automatically re-arm the test each time the vehicle comes to a stop |
| TstDist mi/km*1000 | Target distance checkpoint |
| TstSpd MPH/kph*1000 | Target full-speed checkpoint |
| Veh Weight/Mass | Vehicle mass entry |

### How the Test Works

1. **Arm** the test (manually or auto).
2. **Status: "Drag Ready"** — waiting for vehicle to stop.
3. Bring the vehicle to a complete stop.
4. Accelerate. **Status: "Drag Test Start"** appears.
5. The device records elapsed time and fuel used as you pass each checkpoint:
   - **HALF** — half of the target speed reached
   - **FULL** — target speed reached
   - **DIST** — target distance reached
6. **Status: "Drag Finished"** when all three checkpoints are cleared.
7. Press a button to view the stats screen showing time, fuel used, distance, FE, and estimated horsepower for each checkpoint.

In Auto-Arm mode, the best result across multiple runs is kept (best time for each checkpoint).

## 13. Power Management & Sleep

MPGuino monitors vehicle and button activity, and manages its own power state:

| State | Trigger | Effect |
|---|---|---|
| **Active** | Engine running or vehicle moving | Full display, normal operation |
| **Idle** | Engine running but vehicle stopped for > Idle Timeout | Tracks idle fuel use; may show idle overlay |
| **EOC** | Vehicle moving but fuel injector off for > EOC Timeout | Tracks EOC (engine-off coasting) |
| **Park** | Engine off AND vehicle stopped for > Park Timeout | Saves trips and cursor positions to EEPROM |
| **Sleep / Display off** | Park state held for > Activity Timeout | Shuts down LCD/TFT; CPU enters idle sleep |
| **Wake** | Any button press, engine start, or vehicle movement | Reinitialises display; optionally resets Current trip |

When DS1307 real-time clock module support is configured, the clock display is shown during sleep instead of a blank screen (backlight is turned off).

## 14. Data Outputs

### Serial Data Logging

Enable via Settings → Display & Format → **DLogSerial (1=Y)**.

Outputs 5 tab-separated values once per half-second sample:
1. Instant fuel economy
2. Instant vehicle speed
3. Injector open time (raw, microseconds)
4. Injector pulse count
5. VSS pulse edge count

Default baud rate: 9600.

### JSON Output

Enable via Settings → Display & Format → **JSONoutput (1=Y)**.

Outputs a JSON object each sample cycle with trip, fuel economy, remaining fuel, and (if enabled) drag-race status.

Default baud rate: 19200.

### Bluetooth

Enable via Settings → Display & Format → **BToutput (1=Y)**. Requires `useBluetooth` compiled in and an HM-10 (or similar) module or Adafruit Bluefruit LE Shield.

Outputs selected data to a paired Android device, and is meant to provide input to the MPGuino app written by abbalooga.

### Debug Terminal

A two-way serial terminal for development use (requires `useDebugTerminal`).

Default baud rate: 38400.

Commands available in full on ATmega2560 debug builds, where the extended monitor features are auto-enabled:
- `?` — brief help
- Button injection (inject virtual button presses)
- SWEET64 program listing and trace
- SWEET64 RAM program assembler (requires `useSWEET64RAMprograms`)
- CPU loading detail (`useDebugCPUreading`)

This feature is meant for debugging and development. Normal functionality does not require nor use this feature.

## 15. Build-time Configuration

All feature flags live in `configs.h`. Key choices:

### Board Selection (pick one)

```c
//#define useLegacyBoard true            // traditional AtMega168/AtMega328 based MPGuino boards, including Arduino Uno R3 based versions
//#define useJellyBeanDriverBoard true   // slightly modified MPGuino build, including a 20MHz AtMega328 processor
//#define useArduinoMega2560 true        // utilizes vastly more capable AtMega2560 processor, found in the Arduino Mega2560 and abbalooga's MPGuino Colour Touch
//#define useAdafruitRGBLCDshield true   // mainly to support TWI implementations of MPGuino boards - this has integrated 2x16 LCD and 5-button support
//#define useTinkerkitLCDmodule true     // TinkerKit! LCD module which uses an AtMega32u4, and has integrated LCD and buttons
//#define useMPGuinoColourTouch true     // similar to useArduinoMega2560, but adding integrated BT and touch LCD support
```

### Core Features

```c
#define useAssemblyLanguage true       // faster low-level 64-bit math, using AtMega assembly language
#define useSavedTrips true             // EEPROM trip persistence
#define trackIdleEOCdata true          // idle / EOC sub-totals
#define useWindowTripFilter true       // smoothed instant FE
#define usePartialRefuel true          // partial refuel entry
#define useAlternatorVoltage true      // alternator voltage display
#define useCPUreading true             // CPU load display screen
#define useDS1307clock true            // DS1307 RTC support
```

### UI Features

```c
#define useDragRaceFunction true
#define useBigFE true                  // allows display of large digit fuel economy
#define useBigDTE true                 // allows display of large digit distance to empty
#define useBigTTE true                 // allows display of large digit time to empty
#define useBarFuelEconVsTime true      // allows display of fuel economy vs. elapsed time, in parameterized time periods
#define useBarFuelEconVsSpeed true     // allows display of fuel economy vs. vehicle speed bands, in parameterized band widths
#define useStatusMeter true            // allows display of an instant fuel economy status meter
#define useSpiffyTripLabels true       // allows usage of CGRAM based function labels in the normal display screens, vs 2 character function labels
#define useSpiffyBigChars true         // provides an alternate font for large digit displays
```

### Output Options

```c
#define useDataLoggingOutput true      // provides a basic output of 5 fixed functions, once every 1/2 second
#define useJSONoutput true             // provides a JSON formatted output of a fixed list of outputs, once every 1/2 second, for use with skybolt's Raspberry PI output device
#define useDebugTerminal true          // provides a basic interactive debug terminal accessible via PuTTY or other terminal program. Refer to developer manual for details
#define useBluetooth true              // provides interactive BT support between MPGuino and abbalooga's MPGuino app
```
